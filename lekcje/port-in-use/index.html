"Address already in use": find which process holds a port (ss, lsof, fuser) and free it

Your app won't start because the port is taken. Reproduce "Address already in use", find the process that holds the port with ss -ltnp, lsof -i and fuser, stop it with a plain kill, and see the proof that fuser -k sends SIGKILL by default (exit status 137), so you can use -TERM instead.

Video coming soon — @ShellProven

Correction (3:24): ps | grep only finds a port number if it appears in the command line — ss -ltnp is the reliable way. Test log

Commands

Exactly as run in the video. Full folder with setup script and log: terminal-tutorials/port-in-use.

# The error
$ socat TCP-LISTEN:8080 -
2026/11/21 21:31:49 socat[45] E bind(5, {AF=2 0.0.0.0:8080}, 16): Address already in use

# ss: who is listening
$ ss -ltnp
State  Recv-Q Send-Q Local Address:Port Peer Address:PortProcess                       
LISTEN 0      5            0.0.0.0:8080      0.0.0.0:*    users:(("socat",pid=43,fd=5))
$ ss -ltnp 'sport = :8080'
State  Recv-Q Send-Q Local Address:Port Peer Address:PortProcess                       
LISTEN 0      5            0.0.0.0:8080      0.0.0.0:*    users:(("socat",pid=43,fd=5))

# lsof and fuser
$ lsof -i :8080
COMMAND PID USER FD   TYPE  DEVICE SIZE/OFF NODE NAME
socat    43 root 5u  IPv4 1034843      0t0  TCP *:8080 (LISTEN)
$ fuser 8080/tcp
8080/tcp:               43
$ lsof -t -i :8080
43

# Free the port with kill
$ kill $(lsof -t -i :8080); sleep 0.5; ss -ltn 'sport = :8080'
State Recv-Q Send-Q Local Address:Port Peer Address:Port
$ (setsid socat TCP-LISTEN:8080,fork SYSTEM:'echo hello' >/dev/null 2>&1 &); sleep 1; ss -ltnp 'sport = :8080'
State  Recv-Q Send-Q Local Address:Port Peer Address:PortProcess                       
LISTEN 0      5            0.0.0.0:8080      0.0.0.0:*    users:(("socat",pid=94,fd=5))

# The trap: fuser -k sends SIGKILL
$ kill $(lsof -t -i :8080); sleep 0.5; (setsid sh -c 'socat TCP-LISTEN:8080,fork SYSTEM:true >/dev/null 2>&1; echo "exit status $?" > /tmp/exit.txt' &); sleep 1
$ fuser -k 8080/tcp; sleep 1; cat /tmp/exit.txt
8080/tcp:              114
exit status 137
$ (setsid sh -c 'socat TCP-LISTEN:8080,fork SYSTEM:true >/dev/null 2>&1; echo "exit status $?" > /tmp/exit.txt' &); sleep 1; fuser -k -TERM 8080/tcp; sleep 1; cat /tmp/exit.txt
8080/tcp:              121
exit status 143

PRACTICE — lesson 14: free a busy port
--------------------------------------
Your new app must listen on TCP port 5000, but it fails with
"Address already in use". Three servers are running in this
container, on ports 3000, 5000 and 5432. The ones on 3000 and 5432
are needed and must keep running.

1. Find the process that listens on port 5000 and write only its
   PID (just the number) to /work/pid.txt.
2. Stop that process so port 5000 is free. It saves its data when
   it gets the polite SIGTERM, so it must not be killed harder
   than that.

Check: sh /practice/check.sh     Answer: /practice/solution.md

Inside, sh check.sh tells you when you are done. Stuck? solution.md — but try first.
