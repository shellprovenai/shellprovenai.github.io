sed for the three things you actually need: replace in place, delete lines, print a range

Learn the three sed jobs you need day to day: replace text (and why the g flag matters), edit a file in place safely with -i.bak and diff, delete comment and blank lines, and print a line range or the lines between two markers. Includes the trap where a careless /#/d deletes a line you wanted, with no backup to restore it.

Commands

Exactly as run in the video. Full folder with setup script and log: terminal-tutorials/sed-essentials.

# Replace: s/old/new/
$ cat app.conf
# app settings
host=localhost
port=8080
admin_port=8080

# links
url=http://localhost:8080/health?port=8080#start
debug=true
$ sed 's/8080/9090/' app.conf
# app settings
host=localhost
port=9090
admin_port=9090

# links
url=http://localhost:9090/health?port=8080#start
debug=true
$ sed 's/8080/9090/g' app.conf | grep 9090
port=9090
admin_port=9090
url=http://localhost:9090/health?port=9090#start
$ grep 8080 app.conf
port=8080
admin_port=8080
url=http://localhost:8080/health?port=8080#start

# Edit in place, with a backup
$ sed -i.bak 's/^port=8080/port=9090/' app.conf
$ diff app.conf.bak app.conf
3c3
< port=8080
---
> port=9090

# The trap: -i without a backup
$ sed -i '/#/d' app.conf && cat app.conf
host=localhost
port=9090
admin_port=8080

debug=true
$ cp app.conf.bak app.conf && sed -i 's/^port=8080/port=9090/' app.conf
$ sed '/^#/d' app.conf
host=localhost
port=9090
admin_port=8080

url=http://localhost:8080/health?port=8080#start
debug=true

# Delete lines
$ sed '/^#/d; /^$/d' app.conf
host=localhost
port=9090
admin_port=8080
url=http://localhost:8080/health?port=8080#start
debug=true
$ sed '2d; $d' app.conf
# app settings
port=9090
admin_port=8080

# links
url=http://localhost:8080/health?port=8080#start

# Print a range
$ sed -n '10,15p' app.log
2026-11-20 10:00:10 INFO request 10
2026-11-20 10:00:11 INFO request 11
2026-11-20 10:00:12 ERROR request 12
2026-11-20 10:00:13 INFO request 13
2026-11-20 10:00:14 INFO request 14
--- START deploy
$ sed -n '/ERROR/p' app.log
2026-11-20 10:00:12 ERROR request 12
2026-11-20 10:00:21 ERROR request 21
$ sed -n '/START/,/END/p' app.log
--- START deploy
2026-11-20 10:00:15 INFO request 15
2026-11-20 10:00:16 INFO request 16
--- END deploy
$ echo "root=/var/www/html" | sed 's|/var/www|/srv/www|'
root=/srv/www/html
