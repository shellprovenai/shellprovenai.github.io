xargs and find -exec done right: spaces in file names, -print0, and parallel jobs

Pipe find into xargs and watch a file name with a space break it, fix it with -print0 and xargs -0, compare find -exec with \; and +, preview a destructive command with echo first, and run jobs in parallel with xargs -P (4 seconds of work in about 1).

Commands

Exactly as run in the video. Full folder with setup script and log: terminal-tutorials/xargs-find-exec.

# The space problem
$ ls
My Report.txt
Q3 plan.txt
logs
notes.txt
old 2.tmp
old1.tmp
$ find . -name '*.txt' | xargs wc -l
3 ./notes.txt
wc: ./My: No such file or directory
wc: Report.txt: No such file or directory
wc: ./Q3: No such file or directory
wc: plan.txt: No such file or directory
3 total

# The fix: -print0 and xargs -0
$ find . -name '*.txt' -print0 | xargs -0 wc -l
 3 ./notes.txt
 2 ./My Report.txt
 1 ./Q3 plan.txt
 6 total

# find -exec: \; or +
$ find . -name '*.txt' -exec echo run {} \;
run ./notes.txt
run ./My Report.txt
run ./Q3 plan.txt
$ find . -name '*.txt' -exec echo run {} +
run ./notes.txt ./My Report.txt ./Q3 plan.txt

# Preview before you delete
$ find . -name '*.tmp' -print0 | xargs -0 echo rm --
rm -- ./old 2.tmp ./old1.tmp
$ find . -name '*.tmp' -print0 | xargs -0 rm -- && ls
My Report.txt
Q3 plan.txt
logs
notes.txt

# Parallel jobs with xargs -P
$ time (printf '1\n1\n1\n1\n' | xargs -n 1 sleep)

real	0m4.006s
user	0m0.005s
sys	0m0.001s
$ time (printf '1\n1\n1\n1\n' | xargs -n 1 -P 4 sleep)

real	0m1.003s
user	0m0.005s
sys	0m0.000s
$ find logs -name '*.log' -print0 | xargs -0 -n 1 -P 4 gzip && ls logs
app 1.log.gz
app 2.log.gz
app 3.log.gz
app 4.log.gz

PRACTICE — lesson 17: xargs and find -exec done right
-----------------------------------------------------
/work/project is a small project full of leftovers. Several file
names have spaces in them, like "old report.bak". Use find with
xargs or -exec:

1. Delete every *.bak file anywhere in /work/project (there are
   four). Nothing else may disappear: notes/draft is a real file
   and must stay. Preview with echo first!
2. Compress every *.log file in /work/project/logs with gzip, one
   file per gzip, up to 4 at a time (xargs -P), so each becomes
   NAME.log.gz. logs/README.txt must stay as it is.

Check: sh /practice/check.sh     Answer: /practice/solution.md

Inside, sh check.sh tells you when you are done. Stuck? solution.md — but try first.
