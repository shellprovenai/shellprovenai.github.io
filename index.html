How it works

Three rules, every lesson.

01

Run first, show second

Each command is executed in a clean container and the recorded output is what you see. If it doesn't work, it doesn't ship.

02

Commands you can copy

Every lesson has a folder in the public terminal-tutorials repository: the commands, a setup script and the real log.

03

Quick check

Two short questions at the end of each video, with the answer a few seconds later. Try them here on the lesson page, too.
